How to read a row

States are copied from the mockup’s own table. Endpoints are the calls that screen makes, without the /api/v1 prefix. Handles lists the HTTP status and code the screen draws a state for; “offline” means it draws the offline state too. The screen name links to its section in the mockup.

Rules every screen shares

  • 401 UNAUTHENTICATED anywhere: U0 “Please sign in again”, number kept (U1 Session expired).
  • 429 TOO_MANY_REQUESTS: retry time on the button or alert (needs the readable retry time in the gap list).
  • Money POSTs retry with the same Idempotency-Key.

Not in this file

  • U0 foundation: shell, states and components, no endpoints of its own.
